# Commandr releases

Commandr is a Mac and web app to help you manage your fleet of iPhones for
social marketing — [commandr.so](https://commandr.so).

Downloads for the Mac app are on the
[Releases](https://github.com/wustudios/commandr-releases/releases) page.

Commandr requires **macOS 14 or later** on an **Apple Silicon** Mac. Intel Macs
are not supported.
