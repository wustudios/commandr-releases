# Commandr releases

Downloads and the update feed for [Commandr](https://commandr.so).

- **Downloads** — see [Releases](https://github.com/wustudios/commandr-releases/releases).
- **Update feed** — `appcast.xml`, read by the app's built-in updater.

Commandr requires **macOS 14 or later** on an **Apple Silicon** Mac. Intel Macs
are not supported.

This repository holds published artifacts only. The source lives elsewhere.
